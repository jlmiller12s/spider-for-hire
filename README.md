# Spider for Hire

A pixel-arcade-inspired website for Spider for Hire, a St. Louis character entertainer specializing in birthday parties, community events, and special visits.

The site includes service packages, event photos and reels, an email-based booking flow, and a hidden one-player neighborhood fighting game.

## Built with

- React and TypeScript
- Vite
- GSAP
- Lenis smooth scrolling
- Vercel

## Local development

```bash
npm install
npm run dev
```

Run `npm run build` to create a production build.
